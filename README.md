# Truflation vs BLS CPI Lead Analysis

Analyze the lead time of Truflation CPI over BLS CPI with three modes:

1. **Visual Alignment:** Manually shift Truflation using a slider to align with BLS CPI.
2. **Correlation Corridor:** Compute correlation for each day-shift and highlight the peak correlation.
3. **R² Corridor:** Compute R² values across day-shifts for additional validation.
